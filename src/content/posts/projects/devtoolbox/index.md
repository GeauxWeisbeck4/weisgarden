## `devtoolbox` - JS/TS Utilities Collection

Just because I'm a software developer doesn't mean that I can't have a toolbox like everyone else. Mine is just... a little bit different, I guess. 

This toolbox will fit anywhere and all you need to do to use it, is download it, call it ito your project, or clone the repository - how neat is that?!?!?!

## Background and Purpose

I really wanted to post my first package onto the [JSR package registry](https://jsr.io), but I couldn't figure out what would be cool to create. I don't know  if I settled for cool, but I settled for something boring so I could have a JSR package published!

Now this project is expanding a bit to include any utilities, scripts, or anything of the like that would be easy to call into my project that I may use quite often. That's `devtoolbox` in a nutshell.
