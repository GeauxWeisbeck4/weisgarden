## Digital Garden Notes

This note discusses how this project works. New here? Start with [[Welcome to WeisGarden]], or jump straight to the [[welcome#Digital Garden Resources|digital garden resources]].

Notes and posts link to each other with `[[wiki-links]]`, and every page lists what links back to it. A link can point at a note or a post by title, file name or id. If a note and a post share a name, the note wins, so add a prefix to be explicit: `[[posts/WeisGarden]]` links to the [[posts/WeisGarden|WeisGarden project post]] and `[[notes/welcome]]` to a note.

The whole garden is mapped in the [graph](/graph/), and a small version follows you around every page so you can see what's nearby.
